Capítulo 1

¿Qué es el Extractor?

El Extractor de Documentos es una herramienta web interna de Droguería Nueva Era que permite convertir documentos de licitaciones, cotizaciones y comparativas de precios en archivos CSV estructurados, listos para importar en cualquier planilla de cálculo o sistema de gestión.

El sistema utiliza Gemini AI (Google) para leer e interpretar el contenido de los documentos de forma inteligente, sin importar el formato o la estructura visual del archivo original.

📄
Licitaciones
Pliegos y cotizaciones de clientes con ítems y cantidades
📊
Comparativas
Tablas de precios entre múltiples proveedores por renglón
🗂️
CSV de salida
Resultado estructurado listo para Excel o sistemas de gestión
¿Qué hace exactamente? Subís un PDF o Excel → el sistema lo lee con IA → te devuelve un archivo CSV con los datos organizados en columnas claras (ítem, cantidad, descripción, origen). No hace falta configurar nada ni conocer el formato interno del documento.
Capítulo 2

Acceso al sistema

La aplicación corre localmente en el servidor de la empresa. Para acceder, abrí cualquier navegador web (Chrome recomendado) e ingresá la siguiente dirección:

http://localhost:8000
Requisito previo El servidor debe estar corriendo antes de acceder. Si la página no carga, avisá al área de sistemas para que inicien la aplicación con el script scripts\run.bat.

¿Qué navegador usar?

✓ Google Chrome ✓ Microsoft Edge ✓ Firefox ⚠ Internet Explorer — NO compatible

Capítulo 4

Módulo Licitaciones / Cotizaciones

Este módulo está diseñado para procesar documentos donde un cliente publica o envía una lista de productos con sus cantidades requeridas. El sistema extrae automáticamente cada ítem, la cantidad solicitada y la descripción del producto.

4.1 · Formatos de archivo aceptados

FormatoExtensiónObservaciones
PDF nativo.pdfCon texto embebido (el más recomendado)
PDF escaneado.pdfSe procesa por visión IA — puede tardar más
Excel moderno.xlsxFormato Excel 2007 en adelante
Excel antiguo.xlsCompatible con versiones anteriores
Imagen JPG.jpg / .jpegFoto o escáner del documento
Imagen PNG.pngCaptura de pantalla o escáner
Tip de rendimiento Los PDFs con texto embebido (no escaneados) se procesan mucho más rápido que las imágenes o PDFs escaneados. Si tenés opción, siempre preferí el PDF descargado directamente del sistema, no fotografías del documento.

4.2 · Convención de nombre de archivo

El nombre del archivo es importante: el sistema extrae el código de cliente a partir de la parte anterior al primer guión bajo (_).

Formato: CLIENTE_descripcion.extension Ejemplos: c1002_compraagil.pdf → cliente: c1002 c1327_LICPUB0426.pdf → cliente: c1327 munic_licitacion_mayo.pdf → cliente: munic
Importante Si el nombre del archivo no contiene guión bajo, el sistema usará el nombre completo como código de cliente. Asegurate de que el nombre empiece con el código correcto antes de subir el archivo.

El código de cliente determina:

  • La carpeta donde se guarda el CSV de salida: data/Salida/CLIENTE/
  • El valor del campo origen en cada fila del CSV

4.3 · Paso a paso

  1. Ir al módulo Licitaciones
    En la pantalla principal, hacé clic en la tarjeta Licitaciones / Cotizaciones y después en Empezar.
  2. Seleccionar el archivo
    Hacé clic en el área de carga o arrastrá el archivo directamente. El sistema mostrará el nombre del archivo seleccionado.
  3. Hacer clic en "Procesar archivo"
    El botón se activa automáticamente cuando hay un archivo seleccionado. La barra de progreso indica que el sistema está trabajando.
  4. Esperar el procesamiento
    El tiempo depende del tamaño y tipo del documento:
    PDF nativo · 15–60 segundos PDF escaneado · 1–5 minutos Imagen · 30–90 segundos
  5. Descargar el CSV
    Cuando el proceso termina, el archivo CSV se descarga automáticamente. También podés encontrarlo en data/Salida/CLIENTE/ en el servidor.
  6. Subir otro archivo (opcional)
    Hacé clic en Subir otro archivo para procesar un nuevo documento sin volver a la pantalla principal.

4.4 · El CSV de salida

El archivo CSV usa punto y coma (;) como separador. Al abrirlo en Excel, seleccioná ese separador en el asistente de importación. Contiene 4 columnas:

ColumnaContenidoEjemplo
item Número de renglón o ítem del documento 1, 2, 3…
cantidad Cantidad solicitada (número entero, sin decimales) 650, 9050, 115900
descripcion Descripción completa del producto o medicamento AMOXICILINA 500 MG COMP
origen Código del cliente (extraído del nombre del archivo) c1002, c1327

Ejemplo de CSV de salida:

itemcantidaddescripcionorigen
1650ACICLOVIR 500 MG INYc1002
270ACICLOVIR 80 MG/ML SUSPc1002
39050ACICLOVIR 800 MG COMPc1002
4100AMIKACINA 100 MG INYc1002
5400AMIKACINA 500 MG INYc1002
¿Cómo abrir el CSV en Excel? Abrí Excel → Datos → Desde texto/CSV → seleccioná el archivo → elegí punto y coma como delimitador → Cargar. Alternativamente, podés renombrar el archivo a .txt y Excel lo abrirá con el asistente automáticamente.
Capítulo 5

Módulo Comparativas

El módulo de comparativas está diseñado para procesar documentos donde se comparan precios de múltiples proveedores para los mismos productos. El sistema identifica automáticamente cada renglón y los precios ofrecidos por cada proveedor.

5.1 · Formatos de archivo aceptados

FormatoExtensiónObservaciones
PDF nativo.pdfFormato más común para comparativas
PDF escaneado.pdfProcesamiento más lento
Excel moderno.xlsxExportaciones de sistemas de compras
Excel antiguo.xlsCompatibilidad con versiones antiguas
OpenDocument.odsFormato LibreOffice Calc
HTML.html / .htmPáginas web de sistemas de compras
Imagen JPG.jpg / .jpegFoto o escáner del documento
Imagen PNG.pngCaptura de pantalla

5.2 · Paso a paso

  1. Ir al módulo Comparativas
    En la pantalla principal, hacé clic en Comparativas → Empezar.
  2. Seleccionar el archivo
    Hacé clic en el área o arrastrá el archivo. Los formatos válidos se listan en la sección 5.1.
  3. Procesar y esperar
    Las comparativas suelen ser documentos más extensos. El tiempo estimado varía según el tamaño:
    Documento corto (hasta 50 renglones) · 30–90 seg
    Documento largo (100+ renglones) · 2–8 minutos
  4. Descargar el CSV
    El archivo se descarga automáticamente al finalizar.

5.3 · El CSV de salida

El CSV de comparativas usa también punto y coma como separador. Las columnas varían según el documento pero siempre incluyen la información de renglón, proveedor y precio:

ColumnaContenido
renglonNúmero de renglón del documento
proveedorNombre del proveedor que cotizó
marcaMarca del producto ofertado
precioPrecio unitario ofertado
clienteCódigo de cliente (del nombre del archivo)
Documentos muy largos Para comparativas con más de 100 renglones, el sistema divide el documento en partes y las procesa secuencialmente. El CSV final contiene todos los renglones unificados. Este proceso puede tomar varios minutos — no cerrés la ventana del navegador mientras espera.
Capítulo 6

Dónde se guardan los archivos

El sistema organiza todos los archivos dentro de la carpeta data/ del servidor. Estas carpetas no se suben al repositorio y solo existen en el servidor local.

data/ ├── Salida/ │ ├── c1002/ │ │ └── c1002_compraagil.csv ← CSV de licitación │ └── c1327/ │ └── c1327_LICPUB0426.csv ← CSV de licitación │ ├── SalidaComparativas/ │ └── c1130/ │ └── c1130_compa.csv ← CSV de comparativa │ └── Procesados/ └── c1002/ └── c1002_compraagil.pdf ← archivo original (movido)
¿Qué pasa con el archivo original? Una vez procesado, el archivo original se mueve a la carpeta Procesados/CLIENTE/ automáticamente. Si necesitás reprocesarlo, tenés que buscarlo ahí y subirlo nuevamente.

Nombre del CSV de salida

El CSV conserva el mismo nombre que el archivo original, con extensión .csv. Si ya existe un archivo con ese nombre, el sistema agrega un número al final:

c1002_compraagil.csv ← primer procesamiento c1002_compraagil_2.csv ← si ya existía el primero c1002_compraagil_3.csv ← y así sucesivamente
Capítulo 7

Deduplicación automática

El sistema detecta automáticamente si un documento ya fue procesado anteriormente y evita el reprocesamiento innecesario.

¿Cómo funciona?

Antes de procesar, el sistema calcula una huella digital única del archivo (llamada SHA-256). Si ya existe un resultado con esa misma huella, el sistema devuelve un error 409 y no vuelve a procesar el documento.

Recibiste el error "Este documento ya fue procesado" Esto significa que subiste exactamente el mismo archivo que ya procesaste antes. El CSV de ese procesamiento anterior ya está disponible en data/Salida/. Si el documento cambió y necesitás reprocesarlo, contactá al área de sistemas.

¿La detección es por nombre o por contenido?

Por contenido. Si cambiás el nombre del archivo pero el contenido es idéntico, el sistema igualmente lo detecta como duplicado. Por el contrario, si el contenido del documento cambió aunque el nombre sea el mismo, se procesa normalmente.

Capítulo 8

Mensajes de error y qué hacer

Si algo sale mal durante el procesamiento, el sistema muestra un mensaje en pantalla. A continuación se describen todos los errores posibles y cómo resolverlos.

Error 409 — Documento ya procesado

Mensaje: "Este documento ya fue procesado"

Causa: El archivo subido es idéntico a uno procesado anteriormente.
Solución: Buscá el CSV en data/Salida/CLIENTE/. Si necesitás reprocesar, contactá a sistemas para borrar el registro anterior.

Error 415 — Formato no soportado

Mensaje: "Tipo de archivo no permitido" o "Formato no soportado: .xxx"

Causa: El archivo tiene una extensión que el sistema no acepta para ese módulo.
Solución: Convertí el archivo al formato correcto (PDF, Excel, etc.) o usá el módulo adecuado. Revisá los formatos aceptados en los capítulos 4.1 y 5.1.

Error 422 — No se detectaron proveedores

Mensaje: "No se detectaron proveedores en el documento"

Causa: Solo aplica al módulo Comparativas. El sistema no pudo identificar la estructura de proveedores en el documento.
Solución: Verificá que el documento efectivamente sea una comparativa de precios con múltiples proveedores. Si el formato es poco usual, contactá a sistemas.

Error 422 — No se pudo procesar el archivo

Mensaje: "No se pudo procesar el archivo: [detalle]"

Causa: El archivo está corrupto, protegido con contraseña, o tiene un formato interno inválido aunque la extensión sea correcta.
Solución: Intentá abrir el archivo localmente para verificar que no está dañado. Si está protegido con contraseña, quitala antes de subir.

Error 429 — Servicio saturado

Mensaje: "El servicio está temporalmente saturado. Intente nuevamente en unos momentos."

Causa: Se superó el límite de requests simultáneos a la API de Gemini.
Solución: Esperá 30 segundos y volvé a intentarlo.

Error 503 — Límite de quota alcanzado

Mensaje: "⚠️ Límite de quota alcanzado. Por favor, contacte al administrador…"

Causa: Se agotó el crédito de la API key de Gemini para el período actual.
Solución: Contactar al área de sistemas para renovar o ampliar la API key. Este error no se resuelve esperando — requiere intervención manual.

Error 500 — Error interno del servidor

Mensaje: "Error interno del servidor"

Causa: Error inesperado en el sistema.
Solución: Intentá nuevamente con el mismo archivo. Si el error persiste, contactá a sistemas indicando el nombre del archivo y el módulo usado.
Capítulo 9

Preguntas frecuentes

¿Puedo subir varios archivos a la vez?

No, el sistema procesa un archivo por vez. Podés abrir varias pestañas del navegador para procesar múltiples documentos en paralelo.

¿El CSV tiene el formato correcto para importar en mi sistema?

El CSV usa punto y coma como separador y codificación UTF-8. Es compatible con Excel, LibreOffice y la mayoría de los sistemas de gestión. Si tu sistema requiere otro separador o codificación, consultá con sistemas.

¿Qué pasa si el procesamiento tarda mucho?

Para documentos muy grandes (PDFs de más de 100 páginas), el procesamiento puede tardar varios minutos. No cerrés la ventana del navegador mientras el progreso esté activo. Si pasaron más de 15 minutos sin respuesta, actualizá la página y volvé a intentarlo.

¿Por qué algunas cantidades pueden aparecer con decimales?

El sistema procesa la columna de cantidades eliminando los decimales automáticamente — siempre obtenés números enteros. Si un documento tiene 475,00 o 475.000, el resultado será 475.

¿Puedo reprocesar un archivo si el resultado fue incorrecto?

Sí, pero primero hay que eliminar el registro anterior de la base de datos (de lo contrario, el sistema lo detecta como duplicado). Contactá a sistemas con el nombre del archivo y te lo resolvemos en el momento.

¿Dónde veo los resultados anteriores?

Los CSVs se guardan en la carpeta data/Salida/CLIENTE/ en el servidor. Todos los procesamiento también quedan registrados en la base de datos Supabase, accesible para el área de sistemas.

¿El sistema funciona con documentos en otro idioma?

Sí. Gemini puede procesar documentos en inglés, español, portugués y la mayoría de los idiomas occidentales. Los documentos en español son los que funcionan mejor dado que es el idioma principal del sistema.

¿Qué pasa si subo un archivo con el nombre equivocado?

El CSV se guardará con el cliente incorrecto en el campo origen. En ese caso, borrá el CSV generado, contactá a sistemas para limpiar el registro, y volvé a subir el archivo con el nombre correcto.
