# Presupuestador v1

First in-house version of the presupuestador: upload a file, verify the extraction, match against the product catalog, and build a presupuesto with the same columns as the Progress presupuestador. Real pricing rules come later; v1 uses a fixed margin.

## Specs

- S1 Flow (L2): "el usuario procese el archivo, luego pase por una verificacion coo la de Oc para ver que se haya extraido correctamente, una vez validado sigue la etapa de maching con el catalogo"
- S2 Class at validation (L2, L26, rewritten by L26): "en la parte de adjuntar el archivo para la validacion no se elije nada es deir se sube un procceso comercial. Luego en la etpa de validacion se elije si es licitacion o directa" (original L2: "se debe elegir 1 si es directa y 2 si es licitacion porque las directas trabajan con stock y las licitaciones no").
- S3 Verification (L2): "una verificacion coo la de Oc para ver que se haya extraido correctamente"
- S4 Catalog matching (L2): "una vez validado sigue la etapa de maching con el catalogo"
- S5 Progress matches (L2): "puedo ver la posibilidad de exportar los macheos que ya se hicieron en progress para no empezar de 0"
- S6 Presupuesto columns (L2): "se crea el presupuesto en el cual va a aparecer numero de renglon,descripcion del producto, cantidad solicitada, precio unitario, precio total unitarioxcantidad, rentabilidad, costo." / "la idea por ahora es tener lo que se tiene en el presupuestador de progress."
- S8 Validation starts the proceso comercial (L25, L26): "Para el presupuesto no tiene que elegir un proceso comemrcial puesto que el presupuesto en si va a iniciar el proceso comercial licitacion" / "no se deberia poder crear un proceso sin ccliente" / "en la etpa de validacion se elije si es licitacion o directa el cliente y el nombre del proceso va a ser para las directas cliente + numero ascendente y para las licitacciones que te pida el nombre de la licitacion y quede cliente + nombre de licitacion".
- S9 No client prompt for directas and licitaciones (L28): "hoy en dia para la extraccion de directas y licitaciones funciona bien sin un prompt espeifico para clientes, asi que se podria sacar eso" / "para las comparativas estaria bueno implementarlo porque cada cliente tiene su formato, pero buenolas comparativas las dejamos para una segunda etapa" (comparativas out of scope here).
- S7 Fixed margin (L3, L4): "vaos a utilixar un margen fijo hasta hacer el otor de reglas" / "puede ser un 30%"
