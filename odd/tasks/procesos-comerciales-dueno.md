# Etapa 2 — un solo dueño de las tablas comerciales

Stage 2 of docs/arquitectura/README.md (deviation X-ARQ-003): the Progress legacy presupuesto import's materialization moves from `services/pcp/imports` into the `comercial` module (today `services/presupuestacion/*`), option B (L3).
Branch `feat/procesos-comerciales-dueno` from `dev` (`a324945`). No migrations.

## Specs

- **S1** Option B (L3), as proposed (L2): "La materialización del presupuesto legado (proceso, ítems, presupuesto y su mapa) se mueve a `comercial`. `pcp` queda solo con lo suyo: los renglones del PCP", "`integracion_progress` le pasa el archivo directo a `comercial`".
  - Implementation lives in `services/presupuestacion/presupuestos/` with a facade `services/presupuestacion/presupuestos/api.py`; `services/integracion_progress/tipos/presupuestos/destino.py` imports from that facade, not from `services.pcp.api`.
  - `services/pcp` no longer writes `procesos_comerciales`, `items_proceso`, `presupuestos`, `presupuesto_items` or `presupuesto_legacy_map`. The PCP legacy import keeps writing only `pcp`, `pcp_legacy_map`, `pcp_renglones` and its historial event.
  - The endpoint `POST /pcp/imports/presupuestos-legacy` keeps its path, roles, request and response (it is consumed by `tests/test_roles_matriz_backend.py`); it calls the facade.
- **S2** Same behavior (L2): "Mantener intacto el comportamiento del import: el mismo resultado, la misma idempotencia y la misma compensación ante fallas" — same `accion` values and counts, reuse by `presupuesto_legacy_map`, and on a partial failure the presupuesto and the proceso are deleted and the original error is raised.
  - Only intended change (L2): "los procesos que cree el import legado van a pasar a tener `created_by` (el usuario del sistema) y el evento de auditoría de creación, como cualquier proceso" — the proceso is created through `procesos_comerciales.service.crear_proceso_comercial` with the importing user (manual upload) or the system user (automatic reception).
- **S3** Guard (L2): "Agregar un test que falle si alguien fuera de `comercial` escribe `procesos_comerciales` o `items_proceso`" — extended to the five tables above; reads stay allowed.
- **S4** Docs (L2): "Corregir el desvío X-ARQ-003 en la documentación" — `services/extraccion` only reads; the pcp entry is resolved; `docs/modulos/pcp`, `docs/arquitectura/{mapa-modulos,integracion-progress,README}.md` and the moved docstrings describe the new owner.

Out of scope: PCP still reads comercial tables directly (`services/pcp/imports/repository.py` reads `presupuesto_legacy_map`, `presupuestos`, `items_proceso`); moving those reads behind the facade is a follow-up.
